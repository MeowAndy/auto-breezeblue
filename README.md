# 🌊 auto-breezeblue

[**BreezeBlue**](https://breezeblue.ai/)(AI 语音平台)每日积分自动签到工具 —— **多账号管理 + 本地 Web 面板 + Windows 计划任务**,纯本地运行,凭据不出本机。

## ✨ 功能

- 🔑 **两种登录方式**
  - **Cookie 回放(推荐)**:从浏览器 DevTools 抓一次 Cookie 粘贴即可,适用于所有账号(包括 Google 登录)
  - **邮箱密码**:脚本直接调用登录接口换会话,并保存会话供后续使用(仅限邮箱注册账号)
- 👥 **多账号管理**:每个账号独立的凭据、启用开关、签到记录;卡片式界面一目了然
- 🚀 **一键签到**:单账号签到 / 全部账号批量签到
- 📊 **状态一览**:余额、每日可领积分、档位徽章(Discord 400/天 · 标准 100/天)、今日是否已签、下次重置时间
- ⏰ **每日自动**:注册 Windows 计划任务,到点为所有启用账号后台签到;另有**开机补签**任务(到点关机错过时,开机自动补)
- 🔁 **会话自愈**:签到遇 401 时,若保存了邮箱密码会自动重登重试;Cookie 失效时面板醒目提示
- 🧩 **零依赖面板**:Web 面板用 Python 标准库实现,仅依赖 `requests`

## 🚀 快速开始

> 要求:Windows 10/11、Python 3.10+

```bat
git clone https://github.com/MeowAndy/auto-breezeblue.git
cd auto-breezeblue
pip install -r requirements.txt
```

双击 **`启动签到面板.bat`**,浏览器会自动打开 `http://127.0.0.1:8765/`,然后:

1. 点「**＋ 添加账号**」
2. 浏览器登录 breezeblue.ai → 按 `F12` 打开开发者工具 → 切到 **Network/网络** → 按 `F5` 刷新 → 点任意一条发往 `breezeblue.ai` 的请求 → 在 **Request Headers/请求标头** 里复制 `Cookie:` 后面的全部内容 → 粘贴进弹窗保存
   (也支持直接粘贴 **Copy as cURL** 的全文,会自动提取)
3. 点「**✅ 开启**」注册每日计划任务,完成!

## ⌨️ 命令行(可选)

```bat
python bb_checkin.py run                 :: 立即签到所有启用账号
python bb_checkin.py list                :: 列出账号
python bb_checkin.py add "cookie串" 名字  :: 命令行添加账号
python bb_checkin.py test                :: 测试所有账号登录态(不签到)
python bb_checkin.py status              :: 查看配置/最近结果/任务状态
python bb_checkin.py install 08:05       :: 注册每日计划任务
python bb_checkin.py remove              :: 移除计划任务
```

## ⚙️ 工作原理(逆向自官网前端)

| 步骤 | 接口 | 说明 |
|---|---|---|
| 登录 | `POST /api/auth/email/continue` | 网页端登录表单走的接口,服务端校验 Firebase 凭据后 `Set-Cookie` 下发 HttpOnly 会话(`breeze_blue_session`) |
| 身份 | `GET /api/me` | 校验 Cookie 是否有效,取昵称/头像 |
| 签到 | `POST /api/credits/daily-claim` | 成功 `{"claimed":true,"credits_issued":400.0}`;重复 `{"already_claimed":true}`;档位服务端自动判定,无需传参 |
| 余额 | `GET /api/credits/summary` | 余额、今日是否已签、下次重置时间等 |

- 积分每天 **UTC 00:00(北京时间 08:00)** 重置,建议任务时间设在 08:05 之后
- 新账号**注册**才需要 Cloudflare Turnstile 人机验证,已有账号的登录/签到不需要,所以脚本可行
- 计划任务通过 `schtasks` 注册,每天定时执行 `python bb_checkin.py run`,另有 `ONLOGON` 开机补签任务

## ❓ FAQ

**Cookie 会失效吗?**
会(由服务端会话有效期决定)。面板会显示「Cookie 失效」,重新抓一次粘贴到「编辑账号」即可。若账号保存了邮箱密码,脚本会自动重登,无需手动干预。

**Google 登录的账号能用邮箱密码方式吗?**
不能,Google 账号在 BreezeBlue 没有密码,请用 Cookie 方式。

**多账号怎么加?**
点「＋ 添加账号」逐个加入即可。注意:同一浏览器登出再登另一个账号后,记得重新抓 Cookie(旧账号的会话可能已随登出失效)。

**关机错过了签到时间怎么办?**
开机补签任务(`ONLOGON`)会在下次开机时自动补签一次,当天已签过会直接跳过。若当天一直没开机,则该天积分无法补领。

**安全吗?**
面板只监听 `127.0.0.1`,外部访问不到;`config.json` 明文保存凭据,已被 `.gitignore` 排除,请勿外传。
